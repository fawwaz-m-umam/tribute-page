# Sultan Mehmed II Tribute Page

A tribute page dedicated to **Sultan Mehmed II (Muhammad Al-Fatih)**, the Ottoman Sultan known for conquering Constantinople in 1453.  
This project was created as part of the **Responsive Web Design Certification** from FreeCodeCamp.

## 📖 About The Project

This tribute page presents information about Sultan Mehmed II, including:

- His early life
- Rise to power
- The conquest of Constantinople
- His achievements and legacy
- Historical impact on the Ottoman Empire and the world

The page is designed using HTML and CSS with a responsive layout to ensure it works well on different screen sizes.

## 🚀 Features

- Responsive design
- Timeline/history section
- Historical images
- Clean and modern UI
- Semantic HTML structure

## 🛠️ Built With

- HTML5
- CSS3
